# Bruchlandung (FatherSonGame V2)

Real-time space strategy game for the browser (PC + tablet), for kids 10+; live at crashlanded.dom-builds.com. Father-son project: Claude builds autonomously, ask Dom only for design questions or hard blockers. Talk to Dom in short, simple German; code, comments and commits in English. Plan: `docs/plan/` (read `05-arbeitsweise.md` and `docs/learnings.md` first).

## Repository

- Bun. `bun run dev` (:5173), `check` (typecheck + lint + tests + build; run before every push), `test` / `coverage` (Vitest), `e2e` (Playwright, screenshots).
- Hooks (`.dev-kit/`, `.dev-kit.json`) lint + typecheck on push; enable per clone with `git config core.hooksPath .husky`. CI (`.github/workflows/ci.yml`): lint, typecheck, coverage, e2e. Its deploy jobs (Worker `bruchlandung`, optional GitHub Pages) run only with repo variable `AUTO_DEPLOY=1`.
- `bun run deploy` (manual) = `tools/deploy.sh`. `bun run rollback:prod` reverts the Worker (`--dry-run` to preview).
- Dom's rule: commit directly to `main`, only with `bun run check` green. No PRs.

## Navigate

- `src/sim/` game rules (pure TS, no three, no DOM; `tsconfig.sim.json` + ESLint), `src/content/` data tables (balance here), `src/render/` Three.js (reads state), `src/ui/` HTML menus, `src/input/`, `src/platform/` (IndexedDB), `src/online/` + `src/net/` client, `server/` Worker + Durable Objects, `tests/e2e`, `tests/live` (against the live site), `tools/` (deploy, balance, models), `docs/adr/` decisions.
- Every player action is a `Command` (`src/sim/commands`); the AI uses commands too. Timers use game time stamps (`finishAt`).

## Conventions

- No `any`, no lint-disable comments, no `--no-verify`. File ≤ 200 lines, function ≤ 40, complexity ≤ 12 (ESLint).
- Every rule in `src/sim/` gets a test; coverage ≥ 80 %.
- Surprising lessons go to `docs/learnings.md`, bigger decisions to `docs/adr/`.

## Boundaries

- Kids play online: chat moderation, rate limits and the parents' page (ADR 0009, 0012) stay on; no tracking beyond onedollarstats on the live host.
- No deploy, secret change or `wrangler secret put` unless authorized. Durable Object classes change only through `migrations` in `wrangler.jsonc`.
- Risky paths: `wrangler.jsonc`, `tools/deploy.sh`, `.github/workflows/**`.
