# FatherSonGame V2 – Plan

Echtzeit-Strategiespiel im Weltraum für den Browser (PC und Tablet).
Ein menschliches Raumschiff macht eine Bruchlandung auf einem Planeten ohne Atmosphäre.
Die Menschen leben in Glaskuppeln, bauen ihre Basis aus, ernten Rohstoffe im ganzen
Sonnensystem und kämpfen gegen eine Alien-Zivilisation, bis eine Seite besiegt ist.

Zielgruppe: Kinder ab 10 Jahren.

Stand: 2026-11-12. Status: **M0 bis M6 gebaut** (siehe [04-arbeitspakete.md](04-arbeitspakete.md)), M7 ist noch Plan.
